# 한소끔(가칭) 홈페이지 시안

햄프씨드 식품 브랜드 '한소끔(가칭)'의 **시안(목업) 단일 정적 페이지**. 내용은 모두 예시이며 실제 업체 정보가 아님.

**상태: 미배포 (GitHub Pages 꺼짐, 비공개 저장소).**

## 구성
- `index.html` 구조·문구 / `style.css` 디자인 / `script.js` 메뉴 토글
- `assets/` 벡터봇 납품 로고(톤B 컬러·반전)·아이콘 9개 SVG
- 빌드·외부 CDN·웹폰트 없음. 글꼴은 시스템 스택(`system-ui, Apple SD Gothic Neo, Malgun Gothic`).

## 미리보기
`python3 -m http.server` 후 http://localhost:8000

## 문구 수정
`index.html`에서 대괄호 `[ ]`·'예)' 표시 문구를 실제 내용으로 교체. 색은 `style.css` 상단 `:root` 변수.

## 자리표시 목록
대표 이미지, 제품 사진 4종(이름·용량·가격), 강점 3개, 브랜드 약속 4개, 생산 5단계 설명, FAQ 4개,
스마트스토어·쿠팡 링크, 전화·이메일·주소, 푸터 사업자 정보(상호·대표·사업자등록번호·통신판매업 신고번호·주소).

## 주의
- 건강·효능 표현 금지(식품 광고 주의). 영양·기능성 문구는 근거 확인 후에만 추가.
- 참고 사이트는 구조·분위기만 참고, 문구·이미지·코드 복제 없음.
